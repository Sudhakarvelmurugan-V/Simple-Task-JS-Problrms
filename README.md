# JavaScript Basic Programming Exercises

## 📌 About This Project

This repository contains 10 basic JavaScript programming exercises to improve logical thinking, problem-solving skills, and programming fundamentals.

## 📚 Topics Covered

### 1. Even or Odd
- Write an arrow function.
- Check whether a number is even or odd.
- Use the modulo (%) operator.

### 2. Result Evaluator – Pass or Fail
- Check student marks between 0 and 100.
- Return "Pass" if marks are greater than or equal to 50.
- Return "Fail" if marks are less than 50.
- Display "Invalid marks" for values outside the valid range.

### 3. Maximum Finder – Largest of Three Numbers
- Write an arrow function.
- Find the largest among three numbers.
- Use conditional statements.
- Do not use built-in Math methods.

### 4. Accumulator – Sum from 1 to N
- Calculate the sum of numbers from 1 to N.
- Use a loop.
- Return the total sum.

### 5. Multiplication Table Generator
- Generate the multiplication table for a given number.
- Print the table from 1 to 10.
- Use a loop.

### 6. Digit Counter – Number Length Finder
- Count the total number of digits in a given number.
- Use a loop.
- Do not use string conversion.

### 7. Number Reverser
- Reverse the digits of a given number.
- Use mathematical operations.
- Use a loop.

### 8. Factorial Engine
- Calculate the factorial of a given number.
- Use a loop.
- Apply the factorial formula.

### 9. Prime Validator
- Check whether a given number is prime or not.
- Use a loop to test divisibility.
- Return true or false.

### 10. Pattern Builder – Star Triangle
- Print a star triangle pattern.
- Use nested loops.
- Increase the number of stars in each row.
